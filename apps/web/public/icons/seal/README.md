# 方寸生成式图标

本目录包含方寸界面使用的 39 枚单色透明 PNG 图标。组件将 PNG 的 Alpha 通道作为 CSS mask，因此图标可继承 `currentColor`，并在 15–28px 的现有界面尺寸中使用。

- 来源：OpenAI 内置图像生成工具（gpt-image-2），由项目团队按统一提示词生成
- 生成日期：2026-08-10；语义补充批次：2026-08-11
- 用途：仅用于方寸产品界面、演示、测试与相关宣传物料
- 使用限制：不得将单枚图标作为独立素材包转售；修改或扩展时应保持单色、透明背景、居中方形画布与篆刻刀痕风格
- 外部素材：无

统一提示词要求为：古代中国篆刻风格的单色 UI 图标，纯黑主体、轻微石刻刀痕、正视方形构图、主体约占画布 62%、在 16px 清晰可辨；先在纯 `#00ff00` 背景上生成，再移除键控背景并缩放为 256×256 RGBA PNG。每枚图标只替换主体语义，禁止文字、水印、投影、渐变、三维效果、装饰场景和外框。

2026-08-11 补充生成 `add`、`archive`、`check`、`copy`、`edit`、`fullscreen`、`history`、`lock`、`play`、`project`、`redo`、`restore`、`rotate`、`save`、`shuffle`、`sliders`、`stamp`、`undo`、`unlock`、`zoom-in`、`zoom-out`，用于拆分此前复用造成的语义歧义。`refresh` 仅表示刷新，`bookmark` 仅表示收藏，`grid` 仅表示网格视图，`book` 仅表示知识与课程。
