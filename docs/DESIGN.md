# 1. 文档目标与设计边界

## 1.1 文档目标

本文件承接 [PRD.md](PRD.md) 中的产品定义，将品牌、功能和内容要求转换为可以被 UI/UX 设计师、前端工程师和产品经理**直接执行**的界面规范。

它重点回答四个问题：

1. 用户**看到什么**（信息层级、视觉呈现）；
2. 用户**如何操作**（交互路径、控件行为）；
3. 不同状态**如何反馈**（空 / 加载 / 成功 / 错误 / 离线 / 降级）；
4. 各页面之间**如何衔接**（跳转、上下文保持、返回策略）。

## 1.2 核心体验目标

> 让首次访问者在 **3 秒内**理解"这里可以生成中国印章"，在 **60 秒内**完成第一枚可导出的印章；同时为专业用户保留足够深度，使产品不沦为简单的篆书字体套框工具。

补充目标（V2.0 新增，对应 PRD 第 10 章）：

> 让用户在完成第一枚印章之后，**至少理解一条关于印章的知识**——知道自己刻的是朱文还是白文、为什么这样排列、属于哪个时代的风格。知识不是另一个栏目，而是印章旁边的一句话。

## 1.3 设计边界

| 边界 | 说明 |
|---|---|
| 平台 | 覆盖 Web 桌面端、平板端和移动端；**优先 Web**，兼容 PWA |
| 资产格式 | 以 **SVG First** 为前提，所有核心印面元素都应具备可编辑矢量语义 |
| V1 不阻塞项 | 3D 石章、实体定制、复杂社区运营不作为 V1 阻塞项，但在信息架构中**预留入口** |
| 视觉基调 | "东方现代主义"：**传统而不复古，克制而不寡淡** |
| 不做的事 | 不做通用矢量编辑器；不做社交媒体；不做字体商店；不追求全站动效炫技 |

## 1.4 与其他文档的分工

| 内容 | 归属 |
|---|---|
| 功能要不要做、优先级、验收标准 | [PRD.md](PRD.md) |
| 长什么样、怎么操作、什么状态 | **本文档** |
| 用什么算法、什么数据结构、什么接口 | [TECH.md](TECH.md) |

界面上出现的**参数名**（如 `distress`、`layout.mode`）必须与 TECH.md 的 Seal DSL 字段一一对应，设计稿中的参数命名不得自创。

## 1.5 设计验收清单

- [ ] 每个页面都有 Empty / Loading / Success / Error / Offline 五态稿
- [ ] 每个交互控件都标注了 Default / Hover / Focus / Active / Selected / Disabled
- [ ] 所有颜色、间距、字号来自 Token，无页面级硬编码
- [ ] 桌面 1440 / 1728、平板 1024、移动 390 四个断点均有稿
- [ ] 印面均为真实 SVG 资产，非位图截图

# 2. 品牌体验与设计原则

## 2.1 品牌定义

| 项目 | 规范 |
|---|---|
| 品牌名 | **方寸 Fangcun** |
| 主 Slogan | **方寸之间，自有天地。** |
| 英文 Slogan | *A world within an inch.* |
| 产品一句话 | 让任何人都能够设计、理解和拥有一枚真正中国印章的数字篆刻平台。 |
| 核心隐喻 | 一方印面虽小，却承载文字、身份、时间与审美。 |
| 体验关键词 | 古拙 / 留白 / 朱砂 / 手作感 / 可编辑 / 克制 |
| 反面关键词 | 花哨 / 拥挤 / 廉价古风 / 黑盒 / 说教 |

## 2.2 六条设计原则

| 原则 | 界面落地 |
|---|---|
| **传统，而不复古** | 使用宋式留白、朱砂红、纸感和篆刻语义；避免满屏祥云、木纹、龙纹和"古风模板"感 |
| **工具优先** | 首页即生成入口，关键操作不藏在介绍页或营销段落之后 |
| **简单生成，深度编辑** | 普通用户先获得自动方案，专业参数在编辑器中逐层展开 |
| **AI 可解释** | AI 输出的是可编辑参数与推荐理由，不是不可控的黑盒位图 |
| **数字而有手作感** | 通过残损、印泥、落印动效和随机印蜕表达真实材料感 |
| **文化可信** | 历史风格、字形来源、阅读方向等信息应有清晰出处与说明 |

## 2.3 第七条原则（V2.0 新增）

| 原则 | 界面落地 |
|---|---|
| **知识随手可得，但从不挡路** | 知识以"可展开的一句话"形式贴附在对象旁边（术语浮层、知识卡角标），默认收起；用户不点开也能完成全部创作流程。禁止使用强制教程、必读弹窗、进度门槛 |

## 2.4 设计禁忌清单

以下元素在方寸的任何界面中**不得出现**：

| 禁忌 | 原因 |
|---|---|
| 满屏祥云 / 水墨飞溅 / 卷轴边框 | 廉价古风，与"传统而不复古"冲突 |
| 大面积朱砂红背景 | 稀释品牌色的符号价值 |
| 毛笔字体做 UI 正文 | 可读性差 |
| 现代 SaaS 玻璃拟态 / 霓虹渐变 | 与纸感材质冲突 |
| 印面加 UI 圆角或投影 | 印面必须遵循印式几何，不受 UI 语言影响 |
| 用普通 UI 字体直接渲染最终印面 | 违反字形资产原则（见 6.2） |
| 强制注册墙挡在首次生成之前 | 违反"工具优先" |
| 自动播放的背景音效 | 干扰专注 |

# 3. 目标用户与核心任务

## 3.1 五类核心用户

| 用户 | 首要任务 | 关键能力 | 成功体验 |
|---|---|---|---|
| **普通用户** | 姓名 / 网名 / 闲章快速生成 | 输入文字、选风格、生成 6–12 个方案、PNG 分享 | 一分钟内得到"像真正篆刻"的结果 |
| **设计师** | 用于 Logo、海报、包装 | SVG 导出、低残损、精确尺寸、可复用参数 | 直接进入 Figma / AI / 印刷流程 |
| **书画用户** | 落款、姓名章、斋号章 | 朱白文、传统阅读方向、反字稿 | 能用于真实作品与刻制 |
| **篆刻爱好者** | 查字、参考古印、排印稿 | 字典、印库、章法编辑、字形变体 | 工具不限制专业判断 |
| **开发者** | 批量生成印章资产 | API、DSL、确定性渲染 | 相同参数可复现相同输出 |

## 3.2 第六类用户（V2.0 新增）

| 用户 | 首要任务 | 关键能力 | 成功体验 |
|---|---|---|---|
| **教育 / 文化用户**（教师、博物馆、文化机构、学生） | 讲解印章、组织课堂与展陈 | 知识卡、时间轴、印面标注层、可投屏演示模式、批量学生作品 | 一节课内讲清"什么是印章"并让学生各做一枚 |

**界面含义**：

- 所有知识内容页需支持**大字投屏模式**（`?present=1`，字号 ×1.5、隐藏侧栏）；
- 印章详情页需提供**标注层开关**，可逐项高亮"边框 / 印文 / 留白 / 界格"；
- 学院课程页需提供**离线可打印版**（打印样式表，去掉导航与动效）。

## 3.3 用户能力与界面深度的映射

界面深度分三层，与用户自我认知一一对应，**任何时候都不强迫用户声明身份**：

| 层 | 触发方式 | 界面表现 |
|---|---|---|
| L1 直觉层 | 默认 | 三个语义滑块（古拙 / 疏密 / 残损）、风格 chips、无术语 |
| L2 结构层 | 进入 Studio | 章法、字形 Variant、边框、印蜕分组参数 |
| L3 专家层 | Studio 内"显示高级参数"开关 | 数值输入、seed、坐标、SVG 复杂度、DSL 查看/编辑 |

L3 的开关状态**持久化到本地**，专业用户不必每次打开。

# 4. 信息架构与导航

## 4.1 四条主转化路径

**主创作路径**

```
首页「印」 → 生成 Create → 专业编辑 Studio → 导出 / 保存
```

**SEO 转化路径**

```
字典 → 字形详情 → 使用此字生成 → 编辑器
```

**文化内容转化路径**

```
印库 → 历史印详情 → 以此风格生成 → 编辑器
```

**知识转化路径（V2.0 新增）**

```
学院文章 / 小百科 → 术语浮层 → 课后练习「用汉印章法生成四字印」 → 编辑器
```

四条路径的共同点：**终点永远是编辑器**。任何内容页面都必须存在一个"把这个变成我的印章"的出口。

## 4.2 一级导航

桌面端一级导航建议固定在顶部：左侧为"方寸"字标，中央为主导航，右侧为搜索、主题 / 语言（后期）、登录头像与"开始生成"按钮。

首页可采用透明 / 融入式导航，进入工具页后切换为轻量实底导航。

| 一级入口 | 主要内容 | URL 建议 |
|---|---|---|
| **印** | 首页与品牌入口 | `/` |
| **生成** | 快速生成器 | `/create` |
| **印库** | 历史印章数据库 | `/seals` |
| **字典** | 篆书字形数据库 | `/dictionary` |
| **篆刻** | 知识课程与文章 | `/academy` |
| **作品** | 用户作品社区 | `/gallery` |
| **项目** | 个人项目与历史版本 | `/projects` |

## 4.4 导航状态规范

| 状态 | 表现 |
|---|---|
| 未滚动（首页） | 导航透明、文字为 Ink、无底线 |
| 已滚动 | 背景 Paper 95% + 背景模糊 8px、出现 1px Border 底线 |
| 当前页 | 文字 Ink 加粗 + 下方 2px 朱砂短线（宽度 = 文字宽度） |
| 工具页（Create / Studio） | 始终实底、高度压缩至 48px |
| 移动端 | 顶部仅保留字标 + 汉堡 + "生成"；主导航进抽屉 |

## 4.5 面包屑与返回

- 内容页（印库 / 字典 / 学院）使用面包屑：`印库 / 汉代 / 广陵王玺`；
- 编辑器**不使用面包屑**，只保留左上角 `←` 返回，返回目标为"来源页"而非固定首页；
- 从内容页进入编辑器时，编辑器顶部显示来源徽标：`来源：广陵王玺（汉）`，点击可回到详情页，**且不丢失当前编辑状态**（本地草稿保留）。

## 4.6 国际化导航

| 语言 | 路径前缀 | 导航文案 |
|---|---|---|
| 简体中文 | `/`（默认） | 印 / 生成 / 印库 / 字典 / 篆刻 / 作品 |
| English | `/en` | Seal / Create / Archive / Dictionary / Academy / Gallery |

# 5. 核心用户旅程

## 5.1 首次生成（Onboarding Journey）

```
输入文字 → 选择风格 → 生成方案 → 选择其一 → 轻量编辑 → 导出 / 保存
```

**关键设计决策**：

- 默认**不强迫注册**。首次成功生成后再以"保存高清项目""同步历史版本"等价值点引导注册，避免在核心 aha moment 前制造摩擦；
- 未登录用户的作品存 localStorage，登录后自动迁移，迁移过程给一条 Toast：`已把 3 枚印章同步到你的账户`；
- 首次生成完成后，在结果区下方出现**一张知识卡**（见 15.2），例如"你刚生成的是**白文印**——印文凹陷，钤出后字为白色，汉代最常见。"这是知识体系唯一的主动曝光点。

## 5.2 专业编辑

```
打开方案 → 切换专业模式 → 编辑字形 / 章法 → 调整边框 / 残损 → 重新盖印 → SVG 导出
```

## 5.3 AI 篆刻师

```
描述意图 → AI 解析 → 展示推荐理由 → 生成 4-6 个方案 → 继续对话 / 手动编辑
```

## 5.4 从内容到创作

```
搜索"小篆 天" → 字典详情 → 选择字形 → 用此字生成 → 保存 / 分享
```

## 5.5 从学习到创作（V2.0 新增）

```
学院《汉印为什么方正》 → 课中互动示例（可拖动的章法对比） → 课后练习按钮 → 编辑器（已预置汉印参数） → 提交练习 → 获得「识汉印」成就
```

**课后练习进入编辑器时**：编辑器顶部出现一条练习条：`练习：用汉印章法生成四字印`，右侧为 `提交练习` 按钮；练习条可关闭，关闭后不再打扰。

## 5.6 刻制辅助旅程（V2.0 新增）

```
完成设计 → 打开「刻制辅助」 → 设置真实尺寸（如 25mm 方） → 生成反字稿 → 打印 / 导出 1:1 PDF
```

界面要点：反字稿必须与正稿**并排展示**并明确标注 `正稿（钤出效果）` / `反稿（上石用）`，避免用户混淆导致废料。

## 5.7 旅程失败点与兜底

| 失败点 | 兜底设计 |
|---|---|
| 输入了生僻字，字库缺失 | 不阻断流程，用现代篆化字形占位并标记 ⚠，允许继续生成 |
| 生成 8 秒未完成 | 先出骨架结果（无纹理），文案：`已排好章法，正在上印泥…` |
| 用户不满意全部候选 | "换一批"按钮 + "告诉 AI 你想要什么"输入框 |
| 用户导出后离开 | 本地保留最近 5 个项目，回访时首页顶部提示 `继续上次的「清风明月」` |

### 6.2.3 字体加载策略

- 仅预加载 **Noto Sans CJK SC Regular** 一个字重（首屏必需）；

- CJK 字体按 **Unicode range 分片**加载（常用 3500 字优先）；
- Mono 仅在 Studio 与 API 文档页按需加载；
- 印面字形**不走 Web Font**，走 Glyph SVG 数据（见 [TECH.md](TECH.md)）。

## 6.5 网格与印面度量

印面本身有独立的度量系统，与 UI 栅格解耦：

| 概念 | 说明 |
|---|---|
| 印面画布 | 归一化 `1000 × 1000` 用户单位（方印），非方印按比例 |
| 边框内缩 | 默认 `borderWidth` 占画布 3–8% |
| 安全区 | 印文不超出内框 92% 范围（除非"借边"开启） |
| 参考网格 | Studio 中可开启：井字格 / 米字格 / 界格 / 田字格 |
| 真实尺寸 | UI 显示 mm，内部换算 `1000 unit = 实际边长` |

暗色**不是全站主题**，只用于三个场景：Studio 沉浸模式、3D 预览、投屏演示。用户可在 Studio 内切换，不影响其他页面。

# 7. 布局、栅格与响应式

## 7.1 断点

| 断点 | 宽度 | 布局策略 |
|---|---|---|
| **Mobile** | `< 768px` | 单列；生成优先；专业参数使用底部抽屉 |
| **Tablet** | `768–1199px` | 两列 / 可折叠侧栏；舞台优先 |
| **Desktop** | `1200–1599px` | 12 栅格；编辑器三段式 |
| **Wide** | `≥ 1600px` | 限制内容最大宽度，编辑器增加预览余量而非无限拉宽 |

营销 / 内容页内容最大宽度建议 **1200–1280px**；阅读类正文 **720–820px**；编辑器则允许占据全视口。

## 7.2 栅格

| 断点 | 列数 | 间距 | 外边距 |
|---|---|---|---|
| Mobile | 4 | 16px | 20px |
| Tablet | 8 | 20px | 32px |
| Desktop | 12 | 24px | 48px |
| Wide | 12 | 24px | auto（容器居中，最大 1280px） |

## 7.3 各页面响应式策略

| 页面 | Mobile | Tablet | Desktop |
|---|---|---|---|
| 首页 | Hero 单列，输入框全宽，风格 chips 横向滚动 | Hero 居中，示例印章两列 | Hero 左文右印或居中大印 |
| 生成器 | 参数折叠为底部抽屉，结果 2 列 | 参数顶部横排，结果 3 列 | 参数左栏，结果 3–4 列 |
| 编辑器 | **舞台全屏 + 底部抽屉参数 + 悬浮工具条** | 左栏可折叠 + 舞台 | 三段式（左属性 / 中舞台 / 右面板） |
| 印库 | 单列卡片，时间轴改为横向滚动 | 两列 | 三列 + 左侧筛选 |
| 字典 | 单字 Hero 全宽，字形 2 列 | 字形 3 列 | 字形 4–6 列 + 右侧详情抽屉 |
| 学院 | 单列阅读 | 单列 + 右侧目录浮出 | 左目录 + 中正文 + 右大纲 |
| 社区 | 2 列瀑布 | 3 列 | 4 列 |

## 7.4 移动端编辑器专项

移动端是最难的场景，规范如下：

```
┌─────────────────────────┐
│ ←  清风明月      ⋯  导出 │  ← 48px 顶栏
├─────────────────────────┤
│                         │
│                         │
│      [ SVG 印面 ]        │  ← 舞台占据剩余全部空间
│                         │
│                         │
├─────────────────────────┤
│ 印式 文字 字形 章法 边框 印蜕│  ← 44px 分段滚动条
├─────────────────────────┤
│ 古拙 ━━━●━━━━            │  ← 抽屉，可上拉至 60vh
│ 疏密 ━━━━●━━             │
└─────────────────────────┘
```

- 抽屉三档高度：收起（0）/ 半开（40vh）/ 全开（75vh）；

- 双指缩放舞台，双击复位；
- 底部保留 `env(safe-area-inset-bottom)`。

## 8.2 页面区域

## 8.4 Hero 动效

Hero 使用一条可中断、可重播的 GSAP 时间线；React 组件卸载或断点切换时必须还原状态，不留下内联样式。

| 阶段 | 动效 | 约束 |
|---|---|---|
| 进入 | “印”字以 400–600ms 极轻浮现 + 纸面阴影落定 | 只播一次，不延迟输入框可用 |
| 输入中 | 逐字篆化预览，单字 180ms 交叉淡入 | 新输入立即覆盖旧动画，不能排队 |
| 章法成形 | 细线格局由散到聚，最后淡出 | 只在首次完整输入 2–4 字时出现 |
| 悬停风格 chip | 印面在 200ms 内切换为该风格 | **不重播盖印动画** |
| 点击生成 | 播放一次盖印动画（下压 → 停顿 → 抬起），随后转场至 `/create` | CTA 不等待动画完成；生成与动画并行 |
| 3D 入口 | SVG 印蜕交叉淡出，石章由 12° 侧角转到正面后停止 | 用户主动打开后才加载 Canvas |
| 用户开启减少动效 | 全部改为不超过 100ms 的透明度变化 | 3D 默认显示静态正面视角 |

首页第二屏提供“**一枚印如何诞生**”滚动叙事：字形 → 章法 → 刀感 → 印泥。使用 ScrollTrigger 将进度绑定原生滚动；桌面端最多固定一个演示区，移动端改为纵向卡片依次出现，禁止全站平滑滚动劫持。

# 9. 生成器 Create

## 9.1 设计目标

快速生成器是普通用户的主战场。设计目标是"**参数少但结果丰富**"。用户应只面对与审美直觉有关的选项，复杂的字形、坐标和版面规则由系统自动处理。

## 9.2 六步参数

| 步骤 | 默认控件 | 系统行为 |
|---|---|---|
| **1 文字** | 1–8 字输入、常用示例 | 检测缺字并给替代字形 / 脚本建议 |
| **2 风格** | 古玺 / 秦印 / 汉印 / 文人 / 鸟虫 / 官印 | 映射历史风格参数包 |
| **3 印式** | 自动 / 方 / 长方 / 圆 / 椭圆 | "自动"根据字数与风格推荐 |
| **4 朱白** | 自动 / 朱文 / 白文 | 自动结合历史风格与字数 |
| **5 强度** | 古拙、疏密、残损三个直觉滑块 | 内部映射多个算法参数 |
| **6 生成** | 生成 6–12 个候选 | 先返回骨架结果，再逐步补齐纹理 |

## 9.3 参数区细则

### 9.3.1 文字输入

| 状态 | 表现 |
|---|---|
| 空 | Placeholder：`输入你想刻下的文字` + 三个示例 chips（清风明月 / 张三之印 / 长乐） |
| 输入中 | 右下角字数计数 `4 / 8`；逐字篆化缩略预览排在输入框下方 |
| 缺字 | 该字下方出现 ⚠ 与虚线框，点击展开：`「囍」在小篆字库中无对应字形` + 三个方案（换字体系 / 现代篆化 / 换字） |
| 超字数 | 输入框边框转 warning，提示 `印章文字建议不超过 8 字，过多会牺牲可读性` —— **提示但不阻断** |
| 敏感内容 | 触发合规检查（见 20.5），提示但允许用户申诉 |

### 9.3.2 风格选择

- 六个风格 chip 横排，每个 chip 上带**该风格的微缩印面预览**（用当前输入文字实时渲染，48px）；
- 悬停展开一行说明：`汉印 · 方正平满 · 白文为主 · 公元前 202–220 年`；
- 选中态：朱砂 2px 描边 + `--cinnabar-100` 底色；
- chip 右上角有 `?` 角标，点击打开该风格的**知识浮层**（见 15.2），这是"随处可学"的核心落点。

### 9.3.3 三个语义滑块

滑块必须同时显示**数值**与**文化语义**：

| 滑块 | 范围 | 语义分档 |
|---|---|---|
| 古拙 | 0–100 | 工整（0–25）/ 端庄（26–50）/ 古朴（51–75）/ 高古（76–100） |
| 疏密 | 0–100 | 疏朗（0–30）/ 匀称（31–60）/ 紧密（61–85）/ 满白（86–100） |
| 残损 | 0–100 | 全新（0–10）/ 微残（11–35）/ 斑驳（36–65）/ 出土（66–100） |

显示格式：`残损 35% · 微残`。数值与语义都可点击，点击语义弹出该效果的**前后对比图**。

### 9.3.4 高级折叠区（V2.0 新增）

默认收起，展开后包含：印边样式、界格、边款（V2）、随机种子、真实尺寸预设。展开状态持久化。

## 9.4 方案结果页

- 候选印章使用**统一尺寸卡片**，卡片默认只显示印面和简短标签，避免参数噪音；
- Hover / 点击展示"**汉印 · 白文 · 满白 · 残损 22%**"等摘要；
- 卡片操作：**选择、收藏、重新生成相似方案、进入编辑**；
- 提供"**换一批**"但**保留已收藏方案**，防止用户丢失好结果。

# 10. 专业编辑器 Studio

## 10.1 布局原则

> **舞台永远是视觉中心。侧栏为可折叠工具，不应让用户感觉自己进入复杂矢量软件。**

| 区域 | 桌面端结构 | 主要内容 |
|---|---|---|
| **顶部工具栏** | 全宽 48–56px | 返回、项目名、Undo/Redo、预览模式、保存、导出 |
| **左侧属性栏** | 280–320px | 印式、文字、字形、章法、边框、印泥、纸张 |
| **中央舞台** | 自适应 | 印面 SVG、参考网格、选中字形 Bounding Box、纸张预览 |
| **右侧面板** | 260–300px，可收起 | 方案历史、图层 / 字形列表、版本快照 |
| **底部状态** | 可选 | 缩放、真实尺寸、SVG 复杂度 / 导出提示 |

## 10.2 编辑层级

编辑器的心智模型是**四个层级**，属性栏按此分组：

1. **印章级**：形状、尺寸、朱白、边框、整体密度。
2. **章法级**：排列方式、列宽、行距、留白、重心。
3. **单字级**：字形 Variant、缩放、位置、旋转、借边 / 顶边。
4. **印蜕级**：残损、飞白、印泥、扩散、随机种子。

V2.0 新增第五层：

5. **附加级**：边款、界格、装饰纹、印谱位置。

## 10.3 专业模式交互

- 点击单字进入字形编辑；再次点击或双击进入 **Variant 选择**；
- 拖动字形时显示**吸附线**，但**不强制机械居中**；
- "**重排章法**"只改变布局，**不替换用户锁定的字形**；"**重新设计**"才允许替换 Variant；
- 每个随机效果都保存 **seed**，确保项目可复现；
- 所有高级操作均支持 **Undo / Redo**。

### 10.3.1 选择与操作

| 操作 | 行为 |
|---|---|
| 单击字形 | 选中，显示 Bounding Box + 四角缩放柄 + 顶部旋转柄 |
| 双击字形 | 打开 Glyph Picker（Variant 选择） |
| 拖动 | 移动，显示吸附线（对齐其他字重心 / 边框内缘 / 画布中线） |
| `Shift` + 拖动 | 约束单轴移动 |
| `Alt` + 拖动缩放柄 | 从中心缩放 |
| 右键 | 上下文菜单：锁定 / 换字形 / 借边 / 重置 / 复制参数 |
| `Esc` | 取消选择 |
| 框选 | 多选字形，可批量缩放与对齐 |

### 10.3.2 锁定机制

锁定是专业用户最重要的功能之一：

| 可锁定对象 | 标识 | 效果 |
|---|---|---|
| 单字字形 | 锁图标在字形角 | "重排章法"不替换该字 Variant |
| 单字位置 | 钉图标 | 重排时该字位置不变 |
| 边框 | 锁图标在边框控件 | 重新设计不改边框参数 |
| 整体章法 | 锁图标在章法分组 | 只改字形不改布局 |

锁定状态在舞台上有**明确视觉标识**（角标 + 虚线框），不能只在面板里体现。

## 10.4 参考网格与辅助

| 辅助 | 快捷键 | 说明 |
|---|---|---|
| 井字格 | `G` | 三分线 |
| 米字格 | `Shift+G` | 对角 + 十字 |
| 界格 | `J` | 印面实际分隔线（会进入最终稿） |
| 安全区 | `B` | 显示 92% 内框 |
| 真实尺寸 | `R` | 按屏幕 DPI 显示 1:1 |
| 反字稿 | `M` | 镜像预览（上石用） |
| 黑白稿 | `K` | 去印泥色，纯黑白 |

> **界格与其他辅助的区别必须极其明确**：界格是印章的一部分（会导出），其他辅助只是屏幕参考（不导出）。界格用 Ink 实线，参考线用 Info 靛青虚线。

## 10.5 右侧面板

| 标签页 | 内容 |
|---|---|
| **版本** | 时间线快照，每次显著操作自动打点；可命名、回滚、对比 |
| **字形** | 当前印面所有字的列表，显示 Variant 来源与锁定状态 |
| **方案** | 生成器带过来的其他候选，可一键切换（保留当前为快照） |

"说明"标签页是知识体系在编辑器的落点——它让用户**知道自己做出了什么**。

## 10.6 边款编辑器（V2.0 新增）

首批实现作为 Studio 参数栏内默认收起的公共组件进入，避免移动端离开当前印面；信息密度继续增长时可复用同一组件到 `/studio/:id/inscription` 独立路由。

| 区域 | 内容 |

# 11. AI 篆刻师

## 11.1 定位

AI 篆刻师更像一位"**会解释的设计顾问**"，而不是聊天机器人占据整个产品。

入口出现在三处：首页输入框旁、生成器顶部、编辑器侧栏。

## 11.2 状态规范

| 状态 | 界面 |
|---|---|
| **空状态** | 一句引导："描述你想要的气质、用途或时代感。" + 示例 chips |
| **解析中** | 展示"正在理解用途 / 风格 / 章法"三段轻量进度 |
| **推荐结果** | 参数摘要 + 1–2 句理由 + 4–6 个印章方案 |
| **继续调整** | 用户可说"再古拙一点""改成适合 Logo""不要边框" |
| **异常** | 明确指出缺字、历史风格冲突或不支持的材质需求，并给可执行替代方案 |

## 11.3 可解释性要求

> 推荐结果必须允许"**查看参数**"，把自然语言需求转换为可理解的 **Seal DSL 摘要**，增强 AI 的可控性和专业可信度。

参数摘要的呈现层次：

```
┌────────────────────────────────────────────┐
│ 我理解你想要：一枚用于书画落款的姓名章        │
│                                             │
│ 风格  汉印        因为落款章多取汉印方正      │
│ 朱白  白文        因为姓名章传统用白文        │
│ 印式  方形 20mm   因为适合小幅作品            │
│ 残损  微残 20%    因为落款不宜过于斑驳        │
│                                             │
│ [查看完整参数]  [不对，我想要…]              │
└────────────────────────────────────────────┘
```

每一行右侧的"因为…"是**知识体系与 AI 的结合点**：AI 不只给参数，还给理由，而理由本身就是印章知识。理由中的术语可点击展开浮层。

## 11.4 示例 chips

空状态提供 6 个示例，覆盖不同用户类型：

- `给我的书法作品刻一枚姓名章`
- `做一个适合品牌 Logo 的现代印章`
- `汉印风格的四字闲章`
- `送给爷爷的祝寿印`
- `茶室用的雅致小印`
- `古玺风格，越古朴越好`

## 11.5 交互约束

| 约束 | 说明 |
|---|---|
| 不占满屏 | AI 面板最大宽度 420px（桌面）/ 底部抽屉（移动） |
| 可随时接管 | 任何 AI 结果都有"手动编辑"出口 |
| 不自动应用 | AI 参数需用户确认才写入项目 |
| 保留历史 | 对话历史可回溯，每轮结果可单独恢复 |
| 明确边界 | AI 不承诺"复刻某大师"，文案使用"接近某风格特征" |
| 失败可用 | AI 不可用时，界面降级为"规则推荐"，不阻断创作 |

## 11.6 AI 需求清单

| 编号 | 要求 | 优先级 |
|---|---|---|
| D-401 | 首个 token 响应 ≤ 1.5s | P1 |
| D-402 | 结果必须可查看 DSL 参数 | P0 |
| D-403 | 每条推荐附 1–2 句理由 | P0 |
| D-404 | 理由中的术语可点击展开知识浮层 | P1 |
| D-405 | AI 不可用时降级为规则推荐 | P0 |
| D-406 | 对话历史可回溯并单独恢复 | P1 |


课程页默认保持阅读模式，并在正文上方提供“投屏模式”和“打印讲义”两个明确命令。`?present=1` 使用更宽版心和大字号，隐藏站点导航、课程路径、课后练习与前后课导航，但保留退出投屏和打印入口；Esc 与“退出投屏”均返回无查询参数的普通阅读页。移动端控制并排占满可用宽度，标题、印面与互动组件允许自然换行，不得产生横向滚动。

打印讲义使用 A4 portrait：移除全部屏幕控制、导航、背景纹理和互动状态，只输出标题、一句话答案、正文、图注和每个互动组件的两枚权威 SVG 对照图。屏幕上的当前选择不能改变讲义事实范围。

## 14.4 课中互动组件（V2.0 新增）

学院文章中可嵌入的交互组件，是"知识即功能"的关键：

| 组件 | 说明 |
|---|---|
| **对比滑块** | 拖动分割线对比两种效果（朱文 / 白文、残损前后、疏 / 密） |
| **参数演示** | 内嵌迷你滑块，实时改变示例印章（如拖动"疏密"看章法变化） |
| **顺序标注** | 点击播放阅读顺序 |
| **字形选择器** | 在文中直接切换字形看差异 |
| **对错示例** | 并排"✗ 常见错误 / ✓ 正确"，如"✗ 从左到右读汉印" |
| **一键练习** | 携带本课参数进入编辑器 |

所有互动组件必须：可键盘操作、有静态降级、不依赖 JS 才能读懂正文。

## 14.6 课堂练习与班级合集

课堂首页沿用学院的宣纸、朱砂与阅读层级，不做成行政后台。第一屏先呈现三个练习卡：时长、一个可见变量、任务提示与“打开 Studio”；它们不依赖账户或云服务。其后才是邀请码入口与教师工作台。未配置 Supabase 时必须保留模板，并用静态状态块说明“云课堂尚未配置”；未登录时只提供账户入口，不显示空表格或假班级。

教师创建课堂时只填写课堂名并选择起始练习。成功后列表显示分组后的 8 位邀请码、开放状态和详情入口；详情页提供复制邀请、关闭 / 重新开放和提交数量。学生通过同一路由进入，选择当前浏览器中的一个项目当前版本，并可填写最多 40 字的课堂别名。重交按钮必须明确写成“替换最终稿”，避免让学生误以为会累积多份版本。

提交卡的视觉主体是从冻结 Seal DSL 重新生成的权威 SVG。教师卡只显示学生自填别名（为空时显示“匿名学习者”）、印文事实、更新时间和 Engine / Glyph 版本；禁止显示邮箱、Auth 用户 ID、头像、排名、点赞或公开主页。学生卡只显示自己的当前最终稿。课堂关闭后既要禁用学生按钮，也要由数据库 RPC 再次拒绝，不能只依赖界面状态。动态邀请码详情页需 `noindex, nofollow`；公开 Gallery 收藏与课堂合集使用完全独立的名称、流程与数据表。

# 15. 印章知识普及界面体系

> **V2.0 全新章节。** 对应 [PRD.md 第 10 章](PRD.md#10-印章知识普及体系)，把"让人看懂印章"从内容栏目变成一套**可复用的界面构件**。

## 15.1 设计立场

知识普及最容易失败的两种做法：

| 反面做法 | 为什么失败 |
|---|---|
| 做一个"知识"栏目，把内容都塞进去 | 用户来是为了做印章，不会主动进栏目 |
| 在创作流程里插入教程弹窗、必读步骤 | 打断心流，用户点"跳过"，知识依然没传达 |

**方寸的做法**：知识**贴附在对象旁边**，以"可展开的一句话"存在。用户在做事的过程中顺手看到，不看也不影响做事。

三条硬规则：

1. **不挡路**：任何知识元素都不得阻塞主流程，不得使用模态弹窗强制阅读；
2. **就近**：知识出现在它解释的那个对象旁边（这个 chip、这个滑块、这枚印章），不是在页面顶部；
3. **一句话优先**：默认只给一句话（≤ 40 字），想深入再点。

## 15.2 三层知识构件

### L1 · 术语浮层（Term Popover）

**用途**：解释单个术语，是密度最高、出现最多的知识构件。

| 项 | 规范 |
|---|---|
| 触发 | 虚线下划线文字（`border-bottom: 1px dashed var(--color-info)`）；悬停 / 点击 / 键盘 Focus + Enter |
| 延迟 | 悬停 300ms 后出现，移出 150ms 后消失 |
| 尺寸 | 最大宽度 320px |
| 结构 | 术语（Serif 16px）+ 一句话释义（≤ 40 字）+ 可选缩略示意图 96px + `了解更多 →` |
| 样式 | Paper-50 底 + `--shadow-float` + 左侧 3px 靛青竖线 |
| 移动端 | 改为点击展开的行内折叠块，非浮层 |
| 无障碍 | `aria-describedby` 关联；可键盘打开与关闭（Esc） |

```
┌──────────────────────────────┐
│▎白文                          │
│  印文凹陷，钤出后字为白色、    │
│  底为红色。汉代最常见。        │
│  ┌────┐                      │
│  │ 印 │  了解更多 →           │
│  └────┘                      │
└──────────────────────────────┘
```

**术语库覆盖（首批 60 个必备）**：朱文、白文、满白、细朱文、古玺、汉印、秦印、鸟虫篆、缪篆、章法、界格、边款、印钮、印泥、钤印、印蜕、拓片、借边、并笔、残损、飞白、回文、反字、闲章、名章、斋号印、收藏印、肖形印、押印、封泥、田字格、日字格、朱白相间、上石、冲刀、切刀、单刀、双刀、青田石、寿山石、昌化石、巴林石、篆刻、金石、印谱、印床、拓包、款识、边跋、阴刻、阳刻、玺、宝、章、印信、图章、方寸、小篆、古玺文、金文、甲骨文。

### L2 · 知识卡（Knowledge Card）

**用途**：在完成某个动作后，给一条与结果相关的知识。

| 项 | 规范 |
|---|---|
| 触发 | 首次生成完成、首次进入编辑器、首次导出、首次查看历史印 |
| 频次 | **每类每日最多一次**，可永久关闭 |
| 位置 | 内容流中（非浮层、非模态），紧贴相关结果下方 |
| 结构 | ⓘ 图标 + 一句话（≤ 50 字）+ 可选缩略对比图 + `了解更多 →` + `×` 关闭 |
| 样式 | 靛青 1px 边框 + Paper-100 底 + `--radius-md`，**无阴影**（表示它不是浮层，不打断） |

```
┌────────────────────────────────────────────────────┐
│ ⓘ 你刚生成的是「白文印」——印文凹陷，钤出后字为    │
│    白色。汉代最常见。   了解朱文与白文 →       ×   │
└────────────────────────────────────────────────────┘
```

**知识卡触发规则表**：

| 触发场景 | 知识内容方向 |
|---|---|
| 生成结果多为白文 | 朱白文的区别 |
| 生成结果为古玺风格 | 古玺的时代与特征 |
| 用户调高残损 > 60% | 残损是出土痕迹，不是刻意做旧的必需 |
| 用户首次进 Studio | 章法是什么、为什么要调整 |
| 用户首次导出 SVG | SVG 可用于刻制与印刷 |
| 用户查看历史印 | 这枚印的时代背景一句话 |
| 用户输入 4 字 | 四字印的常见读序 |

路由 `/wiki/:term`，页面结构：

## 15.4 概念对比组件（Concept Compare）

印章知识中大量是**成对概念**，对比是最高效的解释方式。

| 成对概念 | 组件形式 |
|---|---|
| 朱文 / 白文 | 并排两图 + 反色示意 |
| 古玺 / 汉印 | 并排 + 时代标注 |
| 疏 / 密 | 拖动滑块连续变化 |
| 全新 / 残损 | 拖动分割线 |
| 正稿 / 反稿 | 并排 + 镜像箭头 |
| 冲刀 / 切刀 | 分步线描动画 |

组件规范：

- 两侧必须**同文字、同尺寸**，只有被解释的变量不同；
- 标签在图下方，不覆盖图；
- 支持键盘操作（方向键控制分割线 / 滑块）；
- 减少动效时改为静态两图并排。

## 15.5 识印小测（Quiz）

**用途**：轻量自测，验证理解，产生分享动机。

| 项 | 规范 |
|---|---|
| 入口 | 学院课程末尾、小百科底部、首页"今日一印"旁 |
| 题量 | 5 题 / 组，≤ 2 分钟完成 |
| 题型 | 看图选朱白、判断时代、选正确读序、辨认风格、找出错误 |
| 反馈 | **即时反馈**，答错立刻给解释（而不是最后统一公布） |
| 结果 | 得分 + 可分享卡片 + 薄弱项对应的课程链接 |
| 无压力 | 不显示排行榜、不限时、可重做、不记录失败 |

题目卡结构：

```
┌────────────────────────────────────┐
│  第 2 / 5 题                        │
│                                     │
│           ┌────┐                    │
│           │ 印 │                    │
│           └────┘                    │
│                                     │
│  这枚印是朱文还是白文？               │
│                                     │
│  [ 朱文 ]        [ 白文 ]            │
└────────────────────────────────────┘
```

- 答对：`--color-success` 勾 + `对了。字为白色、底为红色，所以是白文。`
- 答错：**不使用红色打叉**（避免挫败），使用靛青 + `再看一次：字是白色的，所以是白文。`

# 16. 作品社区 Gallery

## 16.1 能力规范

| 能力 | 规范 |
|---|---|
| **作品卡片** | 印面 > 作者 > 风格标签；**不展示过多社交数字** |
| **Remix** | 一键复制印式 / 风格 / 章法 / 残损参数，文字替换为自己的 |
| **收藏** | 私人收藏与公开合集 |
| **发布** | 标题可选，必须保留参数快照和生成来源 |
| **举报 / 审核** | 处理侵权、冒充官方印章、违法内容等 |

## 16.2 反社交媒体化设计

社区是**作品陈列**，不是社交平台：

| 做 | 不做 |
|---|---|
| 显示风格标签 | 显示点赞数排行 |
| 显示"被 Remix 12 次" | 显示粉丝数 |
| 按风格 / 时代浏览 | 无限下拉信息流 |
| 精选策展合集 | 算法推荐流 |
| 作者主页展示作品 | 动态、关注、私信 |

**理由**：印章是慢的、静的。社交计数会把用户注意力从"这枚印好不好"转移到"这枚印多少赞"。

## 16.3 作品卡片

| 元素 | 规范 |
|---|---|
| 印面 | 占卡片 75% 面积，`<SealFrame>` M 尺寸 |
| 标题 | 可选，`--text-sm`，缺省显示印文 |
| 作者 | `--text-xs` Ink-600，头像 20px |
| 风格标签 | 最多 3 个，`--text-xs` |
| Hover | `--shadow-raise` + 浮出 `Remix` / `收藏` |

## 16.4 Remix 流程

```
点击 Remix → 参数预览对话框（显示将复制哪些参数） → 输入你的文字 → 进入编辑器
```

Remix 后的作品发布时**自动标注来源**：`Remix 自 @某某 的《清风明月》`，不可移除。

### R7 P2 当前实现边界

- `/gallery` 与 `/en/gallery` 将策展示例和审核通过的公开作品明确分层；未配置 Supabase 时只显示前者，不伪造用户作品、点赞或收藏状态。
- 项目详情可提交当前不可变版本快照，默认 `pending`；只有 `published` 作品可公开展示、Remix 或举报。
- Remix 对话框说明会继承的视觉结构；新文字重新生成 Glyph，DSL 固定 `meta.remixOf = gallery:<post-id>`，发布时不能移除来源。
- 已发布作品卡片提供不依赖 Hover 的 44px 收藏按钮；登录后可选已有合集或新建合集。新合集默认私有，公开是明确的第二选项；对话框必须说明“只保存引用、不复制 Seal DSL”。`/collections/:id` 与 `/en/collections/:id` 仅显示当前可见集合的来源快照和“练习结构”入口，不显示点赞、关注或排行。
- 举报仅对登录用户可提交，内容只对审核人员可见。项目详情的提交卡片会显示作者自己的 `pending` / `published` / `rejected` / `removed` 状态与审核说明；被驳回或下架时可提交一次 5–500 字申诉。Gallery 先显示最新 12 枚审核作品，只有用户点击 44px“加载更多”按钮才请求下一页；末页收起入口，禁止无限下拉。
- `/creators/:id` 与 `/en/creators/:id` 是只读作者主页。用户必须在账户页主动创建 1–40 字公开笔名和最多 280 字简介；不从邮箱、真实姓名或 Auth 元数据派生。资料页只显示该作者审核通过的作品和明确分页，不显示账户邮箱、关注、私信、动态、排名或社交计数；关闭资料后，作品保留审核展示但不再链接笔名。

## 16.5 举报与审核界面

| 场景 | 界面 |
|---|---|
| 举报入口 | 作品详情页 `⋯` 菜单内，不显眼 |
| 举报类型 | 侵权 / 冒充官方或机构印章 / 违法违规 / 其他 |
| 提交后 | Toast `已收到，我们会在 48 小时内处理` |

# 19. 动效与印章物理感

## 19.1 动效语言与工具分工

方寸的动效关键词是：**沉、稳、克制、有材料重量**。运动要帮助用户看懂“字形—章法—印面—印蜕”的关系，不能把产品做成游戏开场或古风视频模板。

| 层 | 工具 | 负责内容 |
|---|---|---|
| DOM / SVG 交互动效 | GSAP + `@gsap/react` | 入场、切换、盖印时间线、SVG 标注与字形过渡 |
| 滚动叙事 | GSAP ScrollTrigger | 首页“一枚印如何诞生”、历史时间轴、学院图解 |
| 3D 场景 | three.js + React Three Fiber + drei | 石章模型、材质、灯光、相机与手势控制 |
| 简单控件状态 | CSS Transition | hover、focus、颜色与 100ms 内的单属性变化 |

同一交互不混用多套动画系统。GSAP 操作 DOM / SVG ref；React Three Fiber 操作 3D object ref；React state 只保存业务状态，不按帧更新。

## 19.2 动效场景表

| 场景 | 动效 | 时长建议 |
|---|---|---|
| **首屏印章** | 极轻浮现 + 纸面阴影 | 400–600ms |
| **生成** | 先布局后印泥纹理，避免长时间空转 | 500–1200ms |
| **盖印** | 下压 80–120ms → 停顿 → 抬起 180–240ms | 300–450ms |
| **切换字形** | 旧字淡出 / 形态过渡，新字对齐后稳定 | 180–260ms |
| **参数滑块** | 实时反馈，残损类可 50–100ms debounce | 即时 |
| **页面切换** | 轻淡入，不使用大幅横向滑屏 | 160–220ms |
| **内容卡进入视口** | 12–20px 上移 + 淡入；同组轻 stagger | 220–360ms |
| **3D 打开** | 海报交叉淡出，石章从 12° 侧角归正 | 450–700ms |
| **3D 标准视角切换** | 相机沿最短路径移动并减速停稳 | 350–550ms |
| **材质切换** | roughness / color / normal 强度平滑过渡 | 250–400ms |

## 19.3 滚动叙事规范

首页最多设置一段固定视口的滚动叙事，长度不超过 `180vh`。演示内容按四个标签推进：

```text
字形 0% ───── 章法 33% ───── 刀感 66% ───── 印泥 100%
```

- 使用浏览器原生滚动；禁止全站 scroll hijacking；
- ScrollTrigger 的 scrub 只用于解释型演示，普通内容卡使用进入视口后播放一次；
- 固定区内部只动画子元素，不动画被 pin 的容器；
- 视差位移控制在 24px 内，不做大幅横向搬运；
- 移动端不 pin，改为四张纵向卡片；
- 用户滚回时允许反向查看，不强制重播声音或盖印效果；
- 动态内容、字体或图片加载完成后需重新计算触发位置。

## 19.4 盖印动画的使用约束

> "**盖印动画**"只在**首次生成**、用户主动点击"**重新盖印**"或**分享演示**时出现，避免每次微调都播放，造成效率损失。

盖印动画的物理分解：

```
时间    0ms      100ms        200ms         450ms
       ┌──┐      ┌──┐         ┌──┐          ┌──┐
印章   │  │  ↓   │  │   停顿   │  │    ↑     │  │
       └──┘      └──┘         └──┘          └──┘
纸面    —      压痕扩散       印泥渗开        定稿
缩放   1.0       0.97          0.97           1.0
不透明  0         0.6           1.0            1.0
```

- 下压使用 `power2.inOut`（等价视觉曲线遵循 `--ease-in-out`）；
- 抬起使用 `power2.out`（快出慢停）；
- 印泥渗开用 `filter` 微模糊由 1.5px → 0；
- **伴随极轻的纸张形变**（印面周围 2px 范围内的纸纹轻微位移），这是"手作感"的关键细节。

## 19.5 3D 印章体验规范

### 19.5.1 场景构成

| 层 | 规范 |
|---|---|
| 背景 | Paper 色或 Studio 暗色；无星空、雾、粒子、霓虹 |
| 相机 | 35–45° 透视；初始看见印面与一个侧面，避免完全正交的“产品转台感” |
| 主光 | 左上方大面积柔光，表现石材体积 |
| 补光 | 低强度暖色补光，不产生彩色轮廓光 |
| 阴影 | 软接触阴影，仅帮助判断石章与纸面的距离 |
| 材质 | 石材以 roughness、细微 normal 和低饱和纹理表达；不得使用高镜面塑料感 |
| 印面 | 与当前 Seal DSL 的 SVG 几何一致；3D 只做派生展示 |

### 19.5.2 交互

- 拖动旋转，滚轮 / 双指缩放，双击或按钮复位；
- 提供“印面 / 侧面 / 印钮”三个明确按钮，不能要求用户自己找角度；
- 旋转范围允许完整环绕，俯仰限制在 `-30°…65°`，避免翻到难以恢复；
- 用户操作时停止所有自动相机运动；松手后不继续惯性旋转超过 600ms；
- 首次打开只做一次 12° → 0° 的迎面转动，随后静止；
- 材质与边款切换保留当前相机角度，不突然复位；
- 材质选择器保持单行横向滚动，每项同时提供名称、色样与 `aria-pressed`；静态海报态也可切换，不以加载 WebGL 为前提；
- 青田 / 寿山 / 昌化 / 巴林 / 铜 / 玉 / 木 / 陶使用低饱和 PBR 参数与确定性纹理；铜、玉、木、陶不伪装成可直接石刻的材质；
- 方 / 长方印边款贴合平面，圆印四面边款分别贴合 90° 圆柱段；界面必须以“平面贴合 / 曲面 UV”提供静态等价说明；
- 单刀显示为浅而窄的凹凸贴图，双刀显示为更深、更宽的凹凸贴图；这只是轻量预览，不使用“真实挖刻”或“扫描刀痕”等措辞；
- 印面可从权威 Seal Engine SVG 的 `data-char` Glyph 路径派生浅层网格：朱文向印面外浅凸，白文向石体内浅凹；固定深度不得超过 `0.04` 场景单位，失败时保留原 SVG 纹理，且不得称为扫描、实体布尔挖刻或生产几何；
- 历史印查看器不显示可编辑材质选择器，材质与三维尺寸来自馆藏结构化事实；模型可按最长边缩放以适应视口，但静态事实保持原始毫米值；
- 真实盖印模式必须由用户拖动或点击触发，不自动循环。

### 19.5.3 布局与降级

- Canvas 与 SVG 海报使用相同宽高比和容器，切换时 CLS = 0；
- 桌面端 3D 区最小 480×480px，移动端宽度 100%、高度不超过 52vh；
- 加载中继续显示 SVG 海报，只在角落显示轻量进度；
- WebGL 初始化失败、设备能力不足或页面不可见时，切回 SVG 海报；
- 静态降级必须保留材质名、尺寸、边款和标准视角图片，信息不可只存在于 3D；
- 3D Canvas 不进入打印版、分享卡片和 SEO 首屏 HTML。

## 19.6 2D / 3D 联动

| 触发 | 2D | 3D |
|---|---|---|
| 修改印文 / 字形 | SVG 即时更新 | 印面纹理 debounce 后更新，不重建相机 |
| 修改印式 | SVG 容器形态更新 | 石章截面平滑切换或短暂交叉淡化 |
| 修改材质 | 不影响印蜕 | 只改变材质，不改变 DSL 几何 |
| 修改残损 | 印蜕即时反馈 | 仅更新印面贴图，不改变石章主体 |
| 查看边款 | 标注侧面位置 | 相机转到对应侧面并高亮边款 |
| 触发盖印 | 显示最终印蜕 | 播放一次下压 / 抬起；结束停在可继续操作的状态 |

## 19.7 动效 Token

| Token | 值 | 用途 |
|---|---|---|
| `--duration-instant` | 100ms | 状态切换、hover |
| `--duration-fast` | 180ms | 字形过渡、Tooltip |
| `--duration-normal` | 260ms | 面板展开、页面淡入 |
| `--duration-slow` | 450ms | 盖印、首屏浮现 |
| `--duration-generate` | 500–1200ms | 生成过程（内容驱动） |
| `--ease-out` | `cubic-bezier(0, 0, .2, 1)` | 进入 |
| `--ease-in` | `cubic-bezier(.4, 0, 1, 1)` | 退出 |
| `--ease-in-out` | `cubic-bezier(.4, 0, .2, 1)` | 移动 |
| `--ease-seal` | `cubic-bezier(.34, 1.2, .64, 1)` | 盖印回弹（**唯一允许的回弹**） |

3D 相机和材质转场沿用相同节奏 Token：标准视角以 GSAP `power2.inOut` 在 520ms 内停稳，连续点击覆盖前一转场；材质贴图直接热替换且保留相机，不用不可靠的逐帧 React state。减少动效时相机直接到达目标位置。

## 19.8 性能友好属性

DOM / SVG 动效严格遵守合成器友好属性：

| 允许 | 禁止 |
|---|---|
| `transform` | `width` / `height` |
| `opacity` | `top` / `left` / `margin` |
| `clip-path` | `padding` / `border-width` |
| `filter`（节制使用） | `font-size` |

`will-change` 仅在动画期间添加，结束立即移除。

3D 场景只在相机移动、材质过渡或用户交互时连续渲染；静止查看器使用按需帧循环。页面离开视口或浏览器标签隐藏后暂停渲染。

## 19.9 减少动效（Reduced Motion）

`prefers-reduced-motion: reduce` 时：

| 原动效 | 降级 |
|---|---|
| 盖印动画 | 直接显示最终印面（0ms） |
| 首屏浮现 | 100ms 透明度变化 |
| 页面切换 | 无过渡 |
| 阅读顺序动画 | 静态显示全部序号 |
| 对比滑块 | 保留（用户主动控制，非自动播放） |
| 成就"钤"动画 | 直接显示 |
| Skeleton 微光 | 静态灰块 |
| 滚动叙事 | 四层静态并列 / 纵向排列，不 pin、不 scrub |
| 3D 入场 / 视角飞行 | 直接切到目标视角；保留用户主动旋转与缩放 |
| 真实盖印 3D | 直接显示石章离纸状态与最终印蜕 |

**原则**：减少动效不等于减少信息——所有通过动画传达的信息必须有静态等价表达。

# 20. 状态、反馈与异常处理

## 20.1 异常处理规范表

| 异常 | 反馈策略 |
|---|---|
| **字库缺字** | 明确显示缺失字符；提供其他文字体系、现代篆化或替换字符建议 |
| **生成超时** | 保留输入参数，允许重试单个方案，**不清空页面** |
| **SVG 过于复杂** | 提示精简残损细节或转为 PNG；**专业用户可继续导出** |
| **未登录保存** | 先本地暂存，再弹出登录以同步 |
| **网络断开** | 编辑器继续本地编辑，恢复后同步 |
| **AI 解析不确定** | 展示"我理解为……"的参数，让用户一键修正 |

## 20.2 五态设计要求

每个页面必须提供五种状态设计稿：

| 状态 | 要求 |
|---|---|
| **Empty** | 专属插画 + 一句说明 + 一个明确动作 |
| **Loading** | 骨架屏（保持最终布局尺寸），**不用全屏 spinner** |
| **Success** | 内容正常 |
| **Error** | 说明发生了什么 + 可做什么 + 重试入口 |
| **Offline** | 顶部常驻条 `离线中，你的编辑会保存在本地` |

## 20.3 错误文案三段式

所有错误必须回答三个问题：

```
发生了什么      生成失败了
为什么          可能是网络不稳定
怎么办          [ 重试 ]  [ 保留参数返回 ]
```

**禁止**的错误文案：`出错了`、`Error 500`、`未知错误`、`请稍后再试`（无具体动作）。

## 20.4 缺字处理详规

缺字是本产品最高频的异常，需要单独规范：

```
┌────────────────────────────────────────┐
│ ⚠ 「囍」在小篆字库中暂无对应字形         │
│                                         │
│ 你可以：                                 │
│  ○ 使用「喜」的重复形式（推荐）           │
│  ○ 使用汉印篆中的近似字形                │
│  ○ 由系统按篆书规则生成（标注为现代篆化）  │
│  ○ 换一个字                              │
│                                         │
│ ⓘ 部分近代汉字在古代篆书中没有对应字形，   │
│    这是正常现象。 了解更多 →              │
└────────────────────────────────────────┘
```

- 默认选中"推荐"方案，**用户不做选择也能继续生成**；
- 现代篆化的字形在印面上有**细微的虚线角标**，导出时可选择是否保留标记；
- 底部知识提示是知识体系在异常场景的落点。

## 20.5 合规提示（V2.0 新增）

对应 PRD 17.2 合规检查器：

# 21. 无障碍与内容规范

## 21.1 核心要求

- 所有印章预览需有**可读替代文本**，例如"清风明月，汉印白文方印"；
- **不能只依赖红 / 黑区分朱文和白文**，控件必须同时显示文字标签；
- 键盘可完成输入、选择方案、Undo/Redo、打开导出；
- 正文与 UI 对比度满足 **WCAG AA**；纸纹不参与对比计算；
- 历史内容避免"绝对复刻某大师"的宣传表述，使用风格特征和历史语境；
- 中文 UI 文案短、克制、有动作性：生成、重排、重新盖印、入印谱、导出。

## 21.2 无障碍详规（V2.0 扩充）

### 21.2.1 替代文本规范

| 对象 | alt 文本模板 |
|---|---|
| 生成的印章 | `{印文}，{风格}{朱白}{印式}印` → `清风明月，汉印白文方印` |
| 历史印章 | `{印名}，{时代}{材质}{钮式}印，{尺寸}` |
| 字形 | `{字}的{文字体系}字形，出自{来源}` |
| 装饰插画 | `alt=""` + `aria-hidden="true"` |
| 对比图 | 分别描述两侧，并说明差异 |

### 21.2.2 键盘可达路径

必须可纯键盘完成的流程：

1. 首页 → 输入 → 生成 → Tab 遍历候选 → Enter 选择 → 进入编辑器；
2. 编辑器 → Tab 到参数 → 方向键调整 → `Cmd+E` 导出 → Tab 到格式 → Enter 确认；
3. 字典 → `/` 搜索 → 方向键选字形 → Enter → 用此字生成；
4. 学院 → Tab 到术语 → Enter 展开浮层 → Esc 关闭。

### 21.2.3 屏幕阅读器

| 场景 | 要求 |
|---|---|
| 生成完成 | `aria-live="polite"` 播报 `已生成 8 个方案` |
| 参数变更 | 滑块播报数值 + 语义 |
| 错误 | `role="alert"` 立即播报 |
| 舞台上的印面 | 提供 `<title>` 与 `<desc>` 在 SVG 内 |
| 装饰性 SVG | `aria-hidden="true"` |
| 标注层 | 每个标注是可聚焦元素，播报"边框，印章外围的框线" |

| 组合 | 比值 | 标准 |
|---|---|---|
| Ink-800 on Paper-200 | 12.1:1 | AAA |
| Ink-600 on Paper-200 | 6.4:1 | AA |
| Cinnabar-500 on Paper-200 | 5.1:1 | AA（大字 AAA） |
| Paper-50 on Cinnabar-500 | 5.1:1 | AA |
| Info on Paper-200 | 6.0:1 | AA |
| Warning on Paper-200 | 4.8:1 | AA |

**朱砂按钮文字必须用 Paper-50 而非纯白**，纯白在朱砂上有轻微眩光。
