# G1 MVP 五人可用性测试

本脚本用于验证首次访问者能否在无教程、无提示的情况下完成第一枚印章。自动化 E2E 只验证流程可运行，不能替代本测试；所有参与者结果必须真实记录。

## 测试准备

- 招募 5 位无篆刻背景、未使用过方寸的参与者，以 `P01`–`P05` 匿名编号。
- 全员使用同一冻结构建，记录测试 URL、commit、设备、浏览器和视口。
- 开始前征得观察同意；录屏或录音需单独同意。不得记录姓名、原始印文或其他个人信息，仅记录字符数。
- 每位参与者使用干净浏览器状态。主持人只读任务，不解释界面、术语或操作。

## 主持人任务

对参与者说：“请把它当作第一次看到的网站。过程中请说出你在想什么；如果卡住，也请继续尝试。”然后依次给出任务：

| # | 任务 | 通过标准 |
|---|---|---|
| 1 | 打开首页，说出网站用途 | 10 秒内答出“生成 / 设计中国印章”等同义答案；目标 5/5 |
| 2 | 生成一枚写着自己名字的印章 | 90 秒内完成且无提示；目标 5/5 |
| 3 | 让印章看起来更“旧” | 4/5 能找到残损滑块 |
| 4 | 导出图片 | 5/5 成功得到 PNG 或 SVG |
| 5 | 说出朱文、白文及区别 | 至少 3/5 正确 |
| 6 | 找到“这个字还有别的写法吗” | 至少 3/5 找到单字 Variant |

ROADMAP G1 的核心流程底线是至少 4/5 完成输入 → 生成 → 调整 → 导出；同时保留 DESIGN §24.3.1 对任务 1、2、4 的更严格 5/5 目标。两个标准都应在报告中单独列出。
